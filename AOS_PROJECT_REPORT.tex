\section*{Abstract}
\addcontentsline{toc}{section}{Abstract}

This report presents a comprehensive Food Delivery Platform built using microservices architecture. The system comprises 8 independent microservices with 47 RESTful API endpoints, leveraging modern technologies including Docker, RabbitMQ, Redis, Consul, and Traefik. The platform demonstrates distributed systems concepts, fault tolerance, scalability patterns, and DevOps practices with complete CI/CD pipeline.

\textbf{Keywords:} Microservices, Docker, RabbitMQ, Redis, Consul, Distributed Systems

\section{Infrastructure Components}

\subsection{Message Queue - RabbitMQ}
\textbf{Provider:} CloudAMQP \\
\textbf{Purpose:} Asynchronous communication between services

\textbf{Implementation:}
\begin{lstlisting}[language=JavaScript]
async publishEvent(exchange, routingKey, data) {
  this.rabbitmq.publish(exchange, routingKey,
    Buffer.from(JSON.stringify(data)),
    { persistent: true });
}
\end{lstlisting}

\section{Database Design}

\textbf{DBMS:} PostgreSQL 15 (Neon Cloud)

\subsection{Key Tables}
\begin{lstlisting}[language=SQL]
CREATE TABLE users (
  id SERIAL PRIMARY KEY,
  email VARCHAR(255) UNIQUE NOT NULL,
  password_hash VARCHAR(255) NOT NULL,
  role VARCHAR(50) NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE orders (
  id SERIAL PRIMARY KEY,
  user_id INTEGER REFERENCES users(id),
  restaurant_id INTEGER REFERENCES restaurants(id),
  status VARCHAR(50) NOT NULL,
  total_amount DECIMAL(10,2) NOT NULL
);
\end{lstlisting}
